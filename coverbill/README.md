# CoverBill

A credit card payment application supporting:

- Real-time payments
- Scheduled payments
- Recurring payments

CoverBill coordinates the payment lifecycle using external Banking Foundry services such as Atlas, RAFT, Herald, and Document Vault.

The project will be used to explore event-driven payment processing, Kafka, idempotency, retries, transactions, Saga patterns, and other distributed-system concepts.
