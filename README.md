# Banking Foundry

A collection of banking applications and reusable financial services built for experimenting with real-world backend and distributed-system patterns.

## Projects

- **CoverBill** — Credit card payment application.
- **Atlas** — Customer, account, card, and card transaction platform.
- **RAFT** — Funds transfer service.
- **Herald** — Multi-channel notification service.
- **Document Vault** — Document storage and archival service.
